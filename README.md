# 师徒制双向互选配对系统 (Mentor Matching System)

这是一个基于 FastAPI 和 原生 JS 实现的师徒双向互选配对系统，支持实时状态同步。

## 项目结构

项目采用前后端分离架构：

- `backend/`: FastAPI 后端代码，提供 REST API 和 WebSocket 实时通讯。
- `frontend/`: 原生 HTML/JS/CSS 编写的前端界面，无打包构建依赖。
- `docs/`: 存放项目相关文档（如模拟矩阵、规则等）。

## 快速启动 (使用 Docker)

为了方便本地开发和部署，项目提供了 `docker-compose.yml`。

### 前置要求
- 已安装 [Docker](https://www.docker.com/)
- 已安装 [Docker Compose](https://docs.docker.com/compose/)

### 运行步骤
1. 在项目根目录执行以下命令，启动前后端服务：
   ```bash
   docker-compose up -d
   ```
2. 服务启动后，在浏览器中访问：
   - 前端应用：[http://43.163.220.61:4876](http://43.163.220.61:4876) (或 http://localhost:4876)
   - 后端 API：[http://43.163.220.61:8000](http://43.163.220.61:8000) (或 http://localhost:8000)
   - API 文档 (Swagger UI)：[http://43.163.220.61:8000/docs](http://43.163.220.61:8000/docs)

3. 停止服务：
   ```bash
   docker-compose down
   ```

*(注意：持久化数据会保存在 `backend/data` 目录下)*

## 本地独立运行 (非 Docker 环境)

如果你想不使用 Docker，也可以分别启动前后端：

### 启动后端
```bash
cd backend
pip install -r requirements.txt
python app.py
```
*(后端将运行在 `http://localhost:8000`)*

### 启动前端
使用任何静态服务器（例如 VS Code 的 Live Server，或者 Python 自带的服务）启动 `frontend/` 目录。
```bash
cd frontend
python -m http.server 8080
```
*(注意：需要配置代理将 `/api` 和 `/ws` 转发至后端 8000 端口，或者直接修改前端请求路径。为了最佳体验，推荐使用 Docker Compose)*

## 使用指南

系统界面直观，主要通过点击操作完成。为了更好地使用本系统，仅需了解以下**核心机制**与**管理流程**：

### 1. 核心匹配机制（必读）
系统采用**双向选择 + n阶段匹配算法**，旨在兼顾公平与整体匹配率：干事的可选部长数量和部长的可选干事数量都可以在控制台点击⚙️进行配置，还能设置有无优先级选项。**此处以干事可选择四个个有优先级的部长，部长可选择三个无优先级的干事为例**
* **干事侧**：系统会优先尽全力满足所有干事的第一志愿，如果第一志愿无法匹配成功，则会尝试匹配第二志愿，以此类推。
* **部长侧**：部长提交的多个候选人**平权**的（无优先级）。当多名干事竞争同一部长的名额时，系统会触发仲裁机制，在所有竞争者中进行**随机抽签**。该机制可以有效防止干事通过“自断后路“（故意选择非常热门的部长作为第二志愿）来获得优势。（原先的设定机制是多干事竞争同一部长的名额时，系统会检查所有竞争者的下一志愿，如果某干事下一志愿没有空间，则会优先安排该干事和本志愿匹配）
* **自动调剂**：可手动开启，自动配对未满员的部长和未分配的干事

### 使用流程
* **普通用户（部长/干事）**：
  * **登录与填报**：通过各自的专属 PIN 码登录。只有在管理员“开启本轮选择”后，才能提交志愿，提交志愿后直接锁定，无法修改
* **管理员（控制台）**：
  * **入口**：点击右上角“控制台”，输入 Admin PIN 码（默认 `admin888`，可在设置中修改）。
  * **开启本轮和结算本轮**：点击后开启选择，干事和部长都可以进行选择。当所有人都锁定了自己的选择，结算本轮按钮会亮起，点击可结算本轮结果。如果有人未提交，结算本轮按钮不会亮起，此时需要使用强制结算，强制结算后，**未提交的部长/干事将自动轮空**，无法在当前轮次完成匹配。
  * **开启下一轮**：结算本轮后，点击开启下一轮
  * **自动调剂**：可手动开启，自动配对未满员的部长和未分配的干事
  * **设置**：可设置干事的可选部长数量和部长的可选干事数量，还能设置有无优先级选项，以及重置数据库
  * **调试模式**：点击后开启调试模式，此时部长和干事会随机做出选择，可以借此查看系统运行是否正常
  * **PIN码配置**：此处可设定部长和干事的名单和PIN码，PIN码默认四位数字，完成修改后需要点击保存修改，还可以根据需要导出该表格为Excel，json，markdown
